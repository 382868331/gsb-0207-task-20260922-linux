# RNA 二级结构预测（带强制配对、未配对分值与相邻堆栈奖励）

离线、纯标准库实现的「带强制配对的 RNA 非交叉（无假结）二级结构预测」可复用模块。
核心算法为**精确区间动态规划**，穷举所有合法结构求最优，**不做任何伪随机抽样**；
约束冲突在输入校验阶段直接拒绝。

打分模型（全部为整数，新增项默认全零）：

- 碱基配对分值：GC/CG=3，AU/UA=2，GU/UG=1；
- **每个位置的未配对分值**：某位置未配对时加上该位置配置的整数分值（可为负）；
- **相邻嵌套配对奖励（stack）**：仅当 `(i, j)` 与 `(i+1, j-1)` 两对同时存在时，
  加一次给定的 stack 分值（可为负，表示惩罚）。

这是题面定义的简化离散打分模型，**不使用真实热力学参数，也不宣称预测真实 RNA 能量**。

## 环境与依赖

## 公共接口

```python
from rna_fold import fold

result = fold(sequence, constraints=None, *, unpaired_scores=None, stack_score=0)
```

### 参数

- `sequence` (`str`)：RNA 序列，仅允许字符 `A C G U`（大小写敏感，小写拒绝），
  长度 **1 ≤ n ≤ 120**（空串 `""` 也允许，返回空结构）。
- `constraints`（可选）：三种形式
  - `None`：自由折叠；
  - `str`：长度必须等于序列长度，支持
    - `.` 该位置自由；
    - `x` 该位置**强制未配**；
    - 成对括号 `()`、`[]`、`{}`、`<>`：括号配平，其两端位置**强制配对**；
  - `dict`：`{"pairs": [(i, j), ...], "unpaired": [k, ...]}`，所有下标 **0 基**。
    - `"pairs"`：强制配对 `(i, j)`，要求 `i < j` 且 `j - i >= 4`；
    - `"unpaired"`：强制未配位置；两个键都可省略。
- `unpaired_scores`（可选，关键字参数）：每个位置未配对时加上的整数分值。两种形式：
  - 长度为 `len(sequence)` 的整数序列（每个位置一个分值）；
  - 映射 `{position: score}`，缺省位置按 0 计。
  默认 `None`（全零）。分值可以是任意整数（含负数）。
- `stack_score`（可选，关键字参数，整数，默认 0）：相邻嵌套配对奖励。
  结构中每出现一对直接相邻嵌套 `(i, j)` + `(i+1, j-1)` 就加一次该分值；
  只嵌套但不相邻（如 `(i, j)` 与 `(i+2, j-1)`）不得分。可为负数（惩罚）。

### 返回值（普通 `dict`，不暴露可变内部状态）

| 键 | 类型 | 含义 |
|---|---|---|
| `score` | `int` | 最大总分：配对分值 + 未配对分值 + 相邻堆栈奖励 |
| `structure` | `str` | 最优结构中**字典序最小**的 dot-bracket（`(`、`)`、`.`） |
| `count` | `int` | 最优结构数量，模 **1 000 000 007** |
| `pairs` | `tuple[(i, j), ...]` | **所有至少出现在某个最优结构中**的配对，按 `(i,j)` 升序 |

字典序按 ASCII 码比较，即 `'(' < ')' < '.'`。

### 合法结构规则（题面契约）

- 只允许 `AU, UA, GC, CG, GU, UG` 六种配对；
- 每对内部至少 **3 个未配位点**：`j - i >= 4`（最小发夹环为 3 nt）；
- 禁止交叉（无假结），每个位置最多参与一个配对。

## 错误语义（异常层级）

所有错误消息都带可定位信息（0 基位置或 `pairs[k]` / `unpaired[k]` 条目名），
**不静默纠正、不猜测**。`fold` 是纯函数，失败不修改入参，不存在部分变更。

- `rna_fold.InvalidSequenceError(ValueError)`：序列类型错误、长度超 120、非法字符。
- `rna_fold.ConstraintError(ValueError)`：约束**结构性**非法：
  - 类型错误、下标越界、整数位置传入 `bool`/`NaN`/`Infinity`/非整数浮点；
  - 字符串约束长度不符、括号不配平、含非法字符；
  - 强制配对本身不合法（距离不足、碱基不互补）；
  - 两对强制配对共用端点、彼此交叉、或端点同时被强制未配；
  - `dict` 形式含未知键。
- `ValueError` / `TypeError`：`unpaired_scores` / `stack_score` 非法
  （长度不符、位置越界、非整数、`bool`、`NaN`/`Infinity` 等），
  错误消息带可定位信息（如 `unpaired_scores[3]`、`stack_score`）。
- `rna_fold.UnsatisfiableConstraintError(ConstraintError)`：
  约束良构但被**精确搜索证明无解**。当前实现下，单个强制配对的物理可行性
  （距离、互补性）与配对间冲突已在输入校验全部拒绝，因此正常输入不会到达此分支；
  保留该异常是为了让「证明无解」这一语义有稳定、可捕获的公开类型。
- `rna_fold.BudgetExceededError(RuntimeError)`：
  **搜索预算耗尽**（未能证明最优）。它与「证明无解」是刻意分开的两个类型，
  互不构成子类。由于 n ≤ 120 时精确 DP 总是完整枚举整个解空间，本实现**永不
  抛出**该异常；它作为固定错误语义的一部分保留。

数值输入契约：整数参数（含 `unpaired_scores` 的键/值与 `stack_score`）拒绝
`bool`（`True/False` 不当作 1/0）；`float` 的 `NaN`/`Infinity` 分别按名称
拒绝，其他非整数浮点报 `TypeError`。

## 算法与设计取舍

- **双表区间 DP（Zuker 式简化版，无能量模型）**：对半开区间 `[i, j)` 维护两张表：
  - `B[i][j]`：区间**没有**外层配对直接包围时的最优分值；
  - `E[i][j]`：区间**被配对 `(i-1, j)` 直接包围**时的最优分值——只有在这张表里
    选择配对 `(i, j-1)` 才构成相邻嵌套 `(i-1, j)+(i, j-1)`，加上 stack 奖励。
    一旦位置 `i` 未配、或 `i` 与 `t < j-1` 配对，剩余区间都不可能再与外层配对
    相邻，转移回 `B` 表。
  转移为 `B[i][j] = max(up[i] + B[i+1][j],  max_t {w(i,t) + E[i+1][t] + B[t+1][j]})`，
  `t` 从 `i+4` 起，且 `(i,t)` 必须互补、不违反强制约束；`up[i]` 为位置 `i` 的
  未配对分值。因为 stack 奖励取决于区间边界是否实际配对，**必须**区分 `B`/`E`
  两种状态，不能只对最终 dot-bracket 事后补奖励。
  时间 O(n³)、空间 O(n²)；n=120 实测约 0.3 秒。
- **计数唯一性**：分解是规范的（每次剥离区间最左位置：未配，或与唯一的 `t` 配对），
  每个结构对应**恰好一条**分解路径，因此每个结构只计一次；并列最优的分解路径重复
  不会增加计数。测试 `test_structure_counted_once_across_decompositions` 与穷举参考
  的精确计数逐一比对验证。
- **强制约束的处理**：除逐位置的配对/未配限制外，引入「闭区间」表
  `closed[i][j]`——区间内任何有强制配偶的位置，其配偶也必须在区间内。
  DP 只在闭子区间上转移，于是任何与强制配对交叉的选择都会使某个子区间不闭，
  自动不可达，不需要特判交叉。
- **计数**：与最优表同步用加法/组合乘法累加，随时对 1 000 000 007 取模。
- **字典序最小结构**：`B`/`E` 各一张字典表从短到长重建；同一最优分值下，
  `i` 未配的候选为 `"."+...`，`i` 配对的候选为 `"("+...+")"+...`，
  取 ASCII 最小者。配对候选按 `t` 升序取最小。
- **可出现在最优中的配对**：从根区间 `[0,n)` 沿「保持最优分值」的决策做
  可达性传播（同时在 `B`/`E` 两张表上传播）；可达区间上的任何最优配对都至少
  属于一个全局最优结构。
  可达性只由分值表（可行性）决定，**不使用取模后的计数**，因此即使某子结构
  集合数量恰为模数倍数（计数显示 0），配对集合仍然精确。测试
  `test_pair_set_independent_of_count_modulus` 用小模数白盒验证了这一点。

### 与独立参考的关系

`tests/brute_reference.py` 是**从零编写、不导入被测模块**的独立参考：
对 n ≤ 14 递归枚举全部非交叉匹配，再以「事后过滤」方式保留含全部强制配对的
结构（与生产代码的闭区间 DP 是两套独立机制）；未配对分值与 stack 奖励同样按
枚举到的每个结构独立打分。测试在数百个确定性随机序列（固定种子）上逐字段对拍，
覆盖**负 stack 分值**、**未配对更划算**、**强制配对与新评分交互**及
**多分解路径下结构只计一次**等场景。
往返一致性（返回串自身合法、能达到所报分值）仅作为补充断言。

## 数值/误差口径

- 分值与计数均为**整数精确计算**：分值是小整数精确加法；计数只做模
  1 000 000 007 的精确整数运算。**全程无浮点参与**，因此没有浮点误差或容差，
  也不存在用宽容差掩盖边界错误的情况。
- 唯一的浮点出现在 `demo.py` 的耗时显示（`time.perf_counter()`，仅展示用，
  不参与任何结果判定）。

## 已知限制（按本题契约实现，不宣称行业标准兼容）

- 这是题面定义的**简化打分模型**，不是完整 RNA 折叠能量模型（无最近邻能量、
  无温度、无自由能 kcal/mol、无凸包/多分支环能量项；stack 奖励是题面定义的
  离散整数项而非真实堆栈能量），不使用真实热力学参数，**不宣称预测真实 RNA
  能量**，不与 ViennaRNA 等行业标准兼容。
- 禁止假结（非交叉）；不预测三链、修饰碱基、非 `ACGU` 字母（如 N、I）。
- 只输出单一字典序最小最优结构；其余并列最优结构以 `count` 与 `pairs` 概括，
  不逐个枚举（n=120 时枚举全部结构不现实）。
- `BudgetExceededError` 在当前确定性 DP 下不会被抛出；它是为语义完整性保留的
  公开类型。
