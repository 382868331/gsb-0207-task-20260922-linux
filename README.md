# RNA 二级结构预测（带强制配对）+ Boltzmann 配对概率

离线、纯标准库实现的可复用模块，包含两个公开入口：

1. **`fold(...)`**：带强制配对的 RNA 非交叉（无假结）二级结构预测，核心是
   **精确区间动态规划**，穷举所有合法结构求最优，**不做任何伪随机抽样**；
2. **`partition_function(...)`**：在同一个合法结构空间上施加**整数能量模型**
   （六种配对各一个整数能量、每个未配对位置一个整数能量），正温度 `T > 0`
   下计算 Boltzmann 配分函数 `Z = Σ exp(-E/T)`，并返回**配对 / 未配对边缘概率**。
   全程 log 域 inside/outside DP（稳定的 log-sum-exp），限长 20。

两者沿用同一组合法配对规则、同一套强制约束与错误类型；约束冲突都在输入校验阶段直接拒绝。

## 环境与依赖

- Python **3.14.7**（3.10+ 的类型语法即可运行，目标环境为 3.14.7）
- **仅使用 Python 标准库**（`math`、`typing`），安装 Python 后无需安装任何第三方依赖
- 完全离线：不需要网络、账号、密钥、数据库、中间件、云 API 或 Docker

## 公共接口

```python
from rna_fold import fold, partition_function

result = fold(sequence, constraints=None)

pf = partition_function(
    sequence,
    constraints=None,
    *,
    temperature=1.0,
    pair_energies=None,      # 可选：覆盖默认整数配对能量
    unpaired_energy=0,       # 整数：每个未配对位置的能量
)
```

### 参数

- `sequence` (`str`)：RNA 序列，仅允许字符 `A C G U`（大小写敏感，小写拒绝），
  长度 **1 ≤ n ≤ 120**（空串 `""` 也允许，返回空结构）。
- `constraints`（可选）：三种形式
  - `None`：自由折叠；
  - `str`：长度必须等于序列长度，支持
    - `.` 该位置自由；
    - `x` 该位置**强制未配**；
    - 成对括号 `()`、`[]`、`{}`、`<>`：括号配平，其两端位置**强制配对**；
  - `dict`：`{"pairs": [(i, j), ...], "unpaired": [k, ...]}`，所有下标 **0 基**。
    - `"pairs"`：强制配对 `(i, j)`，要求 `i < j` 且 `j - i >= 4`；
    - `"unpaired"`：强制未配位置；两个键都可省略。

### 返回值（普通 `dict`，不暴露可变内部状态）

| 键 | 类型 | 含义 |
|---|---|---|
| `score` | `int` | 最大总分：GC/CG=3，AU/UA=2，GU/UG=1 |
| `structure` | `str` | 最优结构中**字典序最小**的 dot-bracket（`(`、`)`、`.`） |
| `count` | `int` | 最优结构数量，模 **1 000 000 007** |
| `pairs` | `tuple[(i, j), ...]` | **所有至少出现在某个最优结构中**的配对，按 `(i,j)` 升序 |

字典序按 ASCII 码比较，即 `'(' < ')' < '.'`。

### 合法结构规则（题面契约）

- 只允许 `AU, UA, GC, CG, GU, UG` 六种配对；
- 每对内部至少 **3 个未配位点**：`j - i >= 4`（最小发夹环为 3 nt）；
- 禁止交叉（无假结），每个位置最多参与一个配对。

### `partition_function`：配分函数与配对边缘概率

`partition_function` 沿用上面的**全部合法结构规则与约束形式**，但长度上限为
**`MAX_PARTITION_LENGTH = 20`**（`fold` 的 120 上限不变）。

#### 能量模型（整数）

```
E(S) = Σ_{(i,j)∈S} e_pair[seq_i seq_j]  +  e_unpaired × (#未配对位置)
Z(T) = Σ_{合法结构 S} exp( -E(S) / T )
```

- `temperature`（关键字参数，默认 `1.0`）：必须是 **`T > 0`** 的有限数
  （`int` 或 `float`；拒绝 `bool`、`NaN`、`Infinity`、非正数，超大 int 无法
  转有限 float 也拒绝）。
- `pair_energies`（可选 `dict`）：配对能量，键为六种**有向**两字母名
  `"GC" "CG" "AU" "UA" "GU" "UG"`，值必须是**整数**（拒绝 `bool`/浮点）。
  允许**部分覆盖**，未给出的键取默认值；含未知键报错。默认表
  （`DEFAULT_PAIR_ENERGIES`，与 `PAIR_SCORES` 对应）：

  | 键 | GC/CG | AU/UA | GU/UG |
  |---|---|---|---|
  | 默认能量 | -3 | -2 | -1 |

- `unpaired_energy`（关键字参数，默认 `0`）：每个未配对位置的整数能量，
  拒绝 `bool`/浮点/`NaN`/`Infinity`。能量绝对值须能转成有限 float。

#### 返回值（普通 `dict`）

| 键 | 类型 | 含义 |
|---|---|---|
| `log_partition` | `float` | `ln Z`（log 域直接算出，不做 `log(sum(exp))` 的朴素计算） |
| `free_energy` | `float` | `-T · ln Z` |
| `temperature` | `float` | 实际使用的温度 |
| `pair_energies` | `dict` | 生效的**完整**六键整数能量表（默认值与覆盖值合并后的独立副本） |
| `unpaired_energy` | `int` | 生效的未配对能量 |
| `pair_prob_matrix` | `list[list[float]]` | `n × n`；`[i][j]` 为配对 `(i,j)`（`i<j`）的边缘概率，其余为 0 |
| `pair_probabilities` | `tuple[(i, j, p), ...]` | 所有 `p > 0` 的合法配对，按 `(i,j)` 升序 |
| `unpaired_probabilities` | `list[float]` | 每个位置未配对的边缘概率 |

边缘概率恒等式（测试在大量序列上逐位校验）：

```
unpaired_probabilities[i] + Σ_j matrix[i][j] + Σ_j matrix[j][i] == 1
```

强制约束下：被强制配对的两端 `matrix[i][j] == 1`、未配对概率为 0；
被 `x` 强制未配的位置未配对概率为 1。约束良构但结构空间为空时抛
`UnsatisfiableConstraintError`（当前校验下作为深度防御保留）。

#### 数值稳定性

全程在 **log 域**做 inside/outside DP：所有求和经稳定的 log-sum-exp
（先减最大值再用 `math.fsum` 求和），单个指数项恒 `≤ 0`，不会上溢；
即使各结构 log 权重相差数百（如 GC 能量 -400），`ln Z` 仍有限且边缘概率
正常归一化。概率在最后一步 `exp(log_p - ln Z)` 一次性还原。

## 错误语义（异常层级）

所有错误消息都带可定位信息（0 基位置或 `pairs[k]` / `unpaired[k]` 条目名），
**不静默纠正、不猜测**。`fold` / `partition_function` 都是纯函数，失败不修改
入参（包括用户传入的 `pair_energies`），不存在部分变更。

- `rna_fold.InvalidSequenceError(ValueError)`：序列类型错误、长度超限
  （`fold` > 120，`partition_function` > 20）、非法字符。
- `rna_fold.ConstraintError(ValueError)`：约束**结构性**非法：
  - 类型错误、下标越界、整数位置传入 `bool`/`NaN`/`Infinity`/非整数浮点；
  - 字符串约束长度不符、括号不配平、含非法字符；
  - 强制配对本身不合法（距离不足、碱基不互补）；
  - 两对强制配对共用端点、彼此交叉、或端点同时被强制未配；
  - `dict` 形式含未知键。
- `ValueError`（温度/能量）：非正温度、`NaN`/`Infinity`、能量键未知、
  整数大到无法转有限 float；温度/能量类型错误为 `TypeError`（含 `bool`）。
- `rna_fold.UnsatisfiableConstraintError(ConstraintError)`：
  约束良构但被**精确搜索证明无解**。当前实现下，单个强制配对的物理可行性
  （距离、互补性）与配对间冲突已在输入校验全部拒绝，因此正常输入不会到达此分支；
  保留该异常是为了让「证明无解」这一语义有稳定、可捕获的公开类型。
- `rna_fold.BudgetExceededError(RuntimeError)`：
  **搜索预算耗尽**（未能证明最优）。它与「证明无解」是刻意分开的两个类型，
  互不构成子类。由于两个入口都是完整枚举整个解空间的精确 DP，本实现**永不
  抛出**该异常；它作为固定错误语义的一部分保留。

数值输入契约：整数参数拒绝 `bool`（`True/False` 不当作 1/0）；`float` 的
`NaN`/`Infinity` 分别按名称拒绝，其他非整数浮点报 `TypeError`。

## 算法与设计取舍

- **区间 DP（Zuker 式简化版，无能量模型）**：对半开区间 `[i, j)`，
  `best[i][j] = max(best[i+1][j],  max_t {w(i,t) + best[i+1][t] + best[t+1][j]})`，
  `t` 从 `i+4` 起，且 `(i,t)` 必须互补、不违反强制约束。
  时间 O(n³)、空间 O(n²)；n=120 实测约 0.15 秒。
- **强制约束的处理**：除逐位置的配对/未配限制外，引入「闭区间」表
  `closed[i][j]`——区间内任何有强制配偶的位置，其配偶也必须在区间内。
  DP 只在闭子区间上转移，于是任何与强制配对交叉的选择都会使某个子区间不闭，
  自动不可达，不需要特判交叉。
- **计数**：与最优表同步用加法/组合乘法累加，随时对 1 000 000 007 取模。
- **字典序最小结构**：第二张区间表从短到长重建；同一最优分值下，
  `i` 未配的候选为 `"."+...`，`i` 配对的候选为 `"("+...+")"+...`，
  取 ASCII 最小者。配对候选按 `t` 升序取最小。
- **可出现在最优中的配对**：从根区间 `[0,n)` 沿「保持最优分值」的决策做
  可达性传播；可达区间上的任何最优配对都至少属于一个全局最优结构。
  可达性只由分值表（可行性）决定，**不使用取模后的计数**，因此即使某子结构
  集合数量恰为模数倍数（计数显示 0），配对集合仍然精确。测试
  `test_pair_set_independent_of_count_modulus` 用小模数白盒验证了这一点。

### 配分函数 inside/outside（log 域）

- **Inside**：对半开区间 `[i, j)`，结构权重和为
  `Q[i][j] = log Σ exp( 未配项 / 配对项 )`，即「i 未配（权重乘未配能量项）」与
  「i 与 t 配对」两类决策的稳定 log-sum-exp；同样只在**闭区间**上转移，
  强制配对 / 交叉处理与 `fold` 完全一致。时间 O(n³)、空间 O(n²)，n=20 亚毫秒。
- **Outside**：从根区间 `[0,n)`（外部权重为 1，log=0）出发，按区间长度**递减**
  把外部上下文推给两个子区间；关键细节是「i 未配」的上下文也必须**累加所有**
  合格上下文（用 logsumexp 而非条件更新），否则多个上下文并存时会漏算——
  该细节由 `AAUAAU` 解析用例（内部位置只能未配，概率必须恰为 1）锁定。
- **配对边缘**：对每个候选 `(i,t)`，把「i 与 t 配对」这一事件在所有可能的
  外层区间 `[i,j)`（`j>t`）下的贡献 logsumexp 起来，再减 `ln Z` 取指数。
- **未配对边缘**：对每个 `i`，把「i 未配」在所有以 i 为左端点的区间下的贡献
  汇总；强制配对位置不进入汇总（其未配概率恒为 0）。
- **log-sum-exp 稳定性**：取项中最大值做位移、`math.fsum` 正确舍入求和，
  单指数项恒 ≤ 0 不上溢，span 达数百的 log 权重仍能正确归一化。

### 与独立参考的关系

`tests/brute_reference.py` 是**从零编写、不导入被测模块**的独立参考：
对 n ≤ 14 递归枚举全部非交叉匹配，再以「事后过滤」方式保留含全部强制配对的
结构（与生产代码的闭区间 DP 是两套独立机制），独立给出：

- `brute_force`：最大分、字典序最小串、精确最优数量与最优配对集合；
- `brute_partition`：直接对枚举出的每个结构求 `exp(-E/T)` 并求和，独立给出
  `Z`、`ln Z`、逐配对与逐位置的精确边缘概率（同样 post-filter 强制配对）。

新功能的期望值**从不调用被测实现生成**：要么来自手算例子（单结构/双结构小序列、
`Z = 1 + k·e^3`）、要么来自解析恒等式（逐位归一化、`∂lnZ/∂(1/T) = −⟨E⟩` 的中心
差分、能量/温度同比例缩放概率不变、`T→0`/`T→∞` 极限）、要么来自上面的独立枚举。

## 数值/误差口径

- `fold`：分值与计数均为**整数精确计算**——分值是小整数精确加法；计数只做模
  1 000 000 007 的精确整数运算。**全程无浮点参与**，因此没有浮点误差或容差，
  也不存在用宽容差掩盖边界错误的情况。
- `partition_function`：全部为双精度（IEEE-754 binary64）**log 域**计算。
  log-sum-exp 用最大值位移 + `math.fsum`；最终边缘概率一次指数还原。对拍独立
  枚举的典型误差在 1e-10 量级，演示打印的逐位归一化误差为 0.00e+00；
  不设掩盖错误的宽容差——对拍用 `delta=1e-9`（n≤14）/ 1e-7（极端能量）。
- 温度允许极小（测试低至 1e-6）但不能为 0 或负；因为总是存在「全未配」这一
  结构，`Z > 0` 恒成立，`ln Z` 不会出现 `-inf`（除非结构空间被约束清空）。
- `demo.py` 的耗时显示（`time.perf_counter()`）仅展示用，不参与结果判定。

## 已知限制（按本题契约实现，不宣称行业标准）

- 能量模型是题面约定的**简化整数模型**：独立配对能量 + 按位未配能量，**无**
  最近邻/堆栈/凸包/多分支环能量项，无 kcal/mol 校准，不与 ViennaRNA 等
  行业标准兼容；不做随机结构采样（本次迭代明确不做），也不做复杂能量联合学习。
- `partition_function` 长度上限为 20（独立枚举对拍 n≤14）；`fold` 保持 120。
- 禁止假结（非交叉）；不预测三链、修饰碱基、非 `ACGU` 字母（如 N、I）。
- `fold` 只输出单一字典序最小最优结构；其余并列最优结构以 `count` 与 `pairs`
  概括，不逐个枚举（n=120 时枚举全部结构不现实）。
- `BudgetExceededError` 在当前确定性 DP 下不会被抛出；它是为语义完整性保留的
  公开类型。
