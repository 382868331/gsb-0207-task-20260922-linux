# RNA 二级结构预测（带强制配对，可选单 H 型假结）

离线、纯标准库实现的「带强制配对的 RNA 非交叉（无假结）二级结构预测」可复用模块。
核心算法为**精确区间动态规划**，穷举所有合法结构求最优，**不做任何伪随机抽样**；
约束冲突在输入校验阶段直接拒绝。本次迭代在保留全部旧接口的前提下，新增**可选的
单 H 型假结模式**：最多允许一对交叉茎（外端点满足 ``i < k < j < l``），不接受任意
交叉网络。

## 公共接口

```python
from rna_fold import fold

result = fold(sequence, constraints=None)
```

### 参数

- `sequence` (`str`)：RNA 序列，仅允许字符 `A C G U`（大小写敏感，小写拒绝），
  空串 `""` 也允许（返回空结构）。默认模式长度 **n ≤ 120**；
  **`allow_pseudoknot=True` 时长度 n ≤ 24**，超过抛 `InvalidSequenceError`。
- `constraints`（可选）：三种形式
  - `None`：自由折叠；
  - `str`：长度必须等于序列长度，支持
    - `.` 该位置自由；
    - `x` 该位置**强制未配**；
    - 成对括号 `()`、`[]`、`{}`、`<>`：括号配平，其两端位置**强制配对**；
  - `dict`：`{"pairs": [(i, j), ...], "unpaired": [k, ...]}`，所有下标 **0 基**。
    - `"pairs"`：强制配对 `(i, j)`，要求 `i < j` 且 `j - i >= 4`；
    - `"unpaired"`：强制未配位置；两个键都可省略。

默认模式下强制配对之间不得交叉；字符串约束按括号族配对，不同族之间也不得交叉。

### 假结模式的新参数（仅关键字参数，均有默认值，旧调用不受影响）

- `allow_pseudoknot` (`bool`，默认 `False`)：是否允许**至多一个**单 H 型假结。
  打开开关**不会强行制造交叉**：无假结结构始终作为候选，只有总分更高时才输出
  假结。必须是真正的 `bool`，传整数或字符串等非布尔值抛 `TypeError`。
- `pseudoknot_penalty` (`int`，默认 `0`)：非负整数，从含假结结构的总分中
  **一次性扣减**。必须是整数（拒绝 `bool`、`NaN`/`Infinity`、非整数浮点）；
  负数抛 `ValueError`。罚分足够大时最优解会退回原无假结结构。

单 H 型假结拓扑（精确）：两条茎的外端点对为 `(i,j)` 与 `(k,l)`，满足
`i < k < j < l`；每条茎由从外向内、**同高度**、逐层交叉的连续嵌套配对组成，
四块臂严格按「茎1左臂 < 茎2左臂 < 茎1右臂 < 茎2右臂」排列；三段环 L1/L2/L3
（允许为空）与尾部区域都用**原无假结算法**独立折叠。整个结构最多含这一个交叉，
环内不允许跨段配对（否则构成第二个交叉）。配对合法性、强制配对/强制未配在假结
模式下继续全部有效，任何位置最多使用一次。

### 返回值（普通 `dict`，不暴露可变内部状态）

| 键 | 类型 | 含义 |
|---|---|---|
| `score` | `int` | 最大总分：GC/CG=3，AU/UA=2，GU/UG=1（假结模式再扣一次罚分） |
| `structure` | `str` | 最优结构中**字典序最小**的扩展 dot-bracket，见下 |
| `count` | `int` | 最优结构数量，模 **1 000 000 007** |
| `pairs` | `tuple[(i, j), ...]` | **所有至少出现在某个最优结构中**的配对，按 `(i,j)` 升序 |
| `pseudoknot` | `dict` 或 `None` | 最优结构含假结时为 `{"stem1": ((i,j),...), "stem2": ((k,l),...)}`，两条茎各自从外向内排列；无假结时为 `None` |

字典序按 ASCII 码比较，即 `'(' < ')' < '.'`。假结模式下 `structure` 用两种括号
族显式标记两条交叉茎：茎1（外左端点较小者）用 `(` `)`，茎2用 `[` `]`；环区及
其他配对仍用 `(` `)`。因此字符全集为 `( ) [ ] .`，ASCII 序为
`'(' < ')' < '.' < '[' < ']'`；同一最优分值下仍在全部候选中取字典序最小。
`pseudoknot` 字段与结构串中的两种括号一一对应，便于程序直接读出两条交叉茎。

### 合法结构规则（题面契约）

- 只允许 `AU, UA, GC, CG, GU, UG` 六种配对；
- 每对内部至少 **3 个未配位点**：`j - i >= 4`（最小发夹环为 3 nt）；
- 默认模式禁止交叉（无假结），每个位置最多参与一个配对；
  假结模式只额外允许上文定义的单个 H 型交叉，任何位置仍最多参与一个配对。

## 错误语义（异常层级）

所有错误消息都带可定位信息（0 基位置或 `pairs[k]` / `unpaired[k]` 条目名），
**不静默纠正、不猜测**。`fold` 是纯函数，失败不修改入参，不存在部分变更。

- `rna_fold.InvalidSequenceError(ValueError)`：序列类型错误、非法字符；默认模式
  长度超 120、假结模式长度超 24 也抛此异常（消息中注明所处模式）。
- `rna_fold.ConstraintError(ValueError)`：约束**结构性**非法：
  - 类型错误、下标越界、整数位置传入 `bool`/`NaN`/`Infinity`/非整数浮点；
  - 字符串约束长度不符、括号不配平、含非法字符；
  - 强制配对本身不合法（距离不足、碱基不互补）；
  - 两对强制配对共用端点、或端点同时被强制未配；默认模式下彼此交叉也直接拒绝；
    假结模式下交叉不在输入阶段拒绝，而交给精确 DP 判定；
  - `dict` 形式含未知键。
- `rna_fold.UnsatisfiableConstraintError(ConstraintError)`：
  约束良构但被**精确搜索证明无解**。默认模式下强制配对的物理可行性与配对冲突
  已在输入校验阶段拒绝；**假结模式**下，要求第二个交叉/任意交叉网、或强制配对
  无法嵌入唯一的单 H 拓扑时，由精确 DP 证明无解并抛此异常。
- 假结参数的数值错误：`pseudoknot_penalty` 为负数抛 `ValueError`；
  `allow_pseudoknot` 非 `bool`、罚分是非整数或 `NaN`/`Infinity` 时，
  按统一数值契约抛 `TypeError`/`ValueError`。
- `rna_fold.BudgetExceededError(RuntimeError)`：
  **搜索预算耗尽**（未能证明最优）。它与「证明无解」是刻意分开的两个类型，
  互不构成子类。由于 n ≤ 120 时精确 DP 总是完整枚举整个解空间，本实现**永不
  抛出**该异常；它作为固定错误语义的一部分保留。

数值输入契约：整数参数拒绝 `bool`（`True/False` 不当作 1/0）；`float` 的
`NaN`/`Infinity` 分别按名称拒绝，其他非整数浮点报 `TypeError`。

## 算法与设计取舍

- **区间 DP（Zuker 式简化版，无能量模型）**：对半开区间 `[i, j)`，
  `best[i][j] = max(best[i+1][j],  max_t {w(i,t) + best[i+1][t] + best[t+1][j]})`，
  `t` 从 `i+4` 起，且 `(i,t)` 必须互补、不违反强制约束。
  时间 O(n³)、空间 O(n²)；n=120 实测约 0.15 秒。
- **强制约束的处理**：除逐位置的配对/未配限制外，引入「闭区间」表
  `closed[i][j]`——区间内任何有强制配偶的位置，其配偶也必须在区间内。
  DP 只在闭子区间上转移，于是任何与强制配对交叉的选择都会使某个子区间不闭，
  自动不可达，不需要特判交叉。
- **计数**：与最优表同步用加法/组合乘法累加，随时对 1 000 000 007 取模。
- **字典序最小结构**：第二张区间表从短到长重建；同一最优分值下，
  `i` 未配的候选为 `"."+...`，`i` 配对的候选为 `"("+...+")"+...`，
  取 ASCII 最小者。配对候选按 `t` 升序取最小。
- **单 H 型假结（可选模式）**：在无假结 DP 之外维护第二张区间表 `best1[i][j]`
（区间内含恰好一个假结）。转移除了「i 未配」「i 与 t 非交叉配对（假结落在
  两个子区间之一）」之外，第三种转移把 i 作为茎1外左端点，枚举茎1/茎2的外
  端点 (i,b)、(c,d) 与共同茎高，三段环用 `best0` 独立折叠，尾部并入区间递
  归。每个交叉结构只在「锚点 = 茎1外左端点」处被枚举一次，因此不可能出现第二
  个交叉；含假结的总分扣一次 `pseudoknot_penalty`。根节点在 `best0` 与
  `best1` 之间取最大，**无假结恒为候选**，平分时合并计数并取全局字典序最小。
  设 n ≤ 24，完整枚举在普通笔记本上毫秒级完成。
- **可出现在最优中的配对**：从根区间 `[0,n)` 沿「保持最优分值」的决策做
  可达性传播；可达区间上的任何最优配对都至少属于一个全局最优结构。
  可达性只由分值表（可行性）决定，**不使用取模后的计数**，因此即使某子结构
  集合数量恰为模数倍数（计数显示 0），配对集合仍然精确。测试
  `test_pair_set_independent_of_count_modulus` 用小模数白盒验证了这一点。

### 与独立参考的关系

`tests/brute_reference.py` 是**从零编写、不导入被测模块**的独立参考：
对 n ≤ 14 递归枚举全部非交叉匹配，再以「事后过滤」方式保留含全部强制配对的
结构（与生产代码的闭区间 DP 是两套独立机制），独立给出最大分、字典序最小串、
精确最优数量与最优配对集合。测试在数百个确定性随机序列（固定种子）上逐字段对拍。
`tests/brute_pseudoknot.py` 是假结模式的独立参考：递归枚举所有匹配后，用一套
**独立的 H 拓扑识别规则**（从最外交叉出发求两条极大连续嵌套茎，校验四块臂有序
与同高逐层交叉）过滤出「无交叉」或「恰好一个 H」的匹配，任意交叉网被拒；测试
对多种罚分与强制配对逐字段对拍。往返一致性（返回串自身合法、能达到所报分值）
仅作为补充断言。

## 数值/误差口径

- 分值与计数均为**整数精确计算**：分值是小整数精确加法；计数只做模
  1 000 000 007 的精确整数运算。**全程无浮点参与**，因此没有浮点误差或容差，
  也不存在用宽容差掩盖边界错误的情况。
- 唯一的浮点出现在 `demo.py` 的耗时显示（`time.perf_counter()`，仅展示用，
  不参与任何结果判定）。

## 已知限制（按本题契约实现，不宣称行业标准兼容）

- 这是题面定义的**简化打分模型**，不是完整 RNA 折叠能量模型（无最近邻能量、
  无温度、无自由能 kcal/mol、无堆栈/凸包/多分支环能量项），不与 ViennaRNA 等
  行业标准兼容。
- 默认模式禁止假结；假结模式只支持**一个**严格单 H 型假结（两条同高连续茎
  交叉），不支持多个假结、K 型/H&H 型交叉网或任意 pseudoknot 网络。
- 假结模式长度上限 **24**（默认模式仍为 120）；不预测三链、修饰碱基、非
  `ACGU` 字母（如 N、I）。
- 只输出单一字典序最小最优结构；其余并列最优结构以 `count` 与 `pairs` 概括，
  不逐个枚举（n=120 时枚举全部结构不现实）。
- `BudgetExceededError` 在当前确定性 DP 下不会被抛出；它是为语义完整性保留的
  公开类型。
