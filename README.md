# RNA 二级结构预测（带强制配对）

离线、纯标准库实现的「带强制配对的 RNA 非交叉（无假结）二级结构预测」可复用模块。
核心算法为**精确区间动态规划**，穷举所有合法结构求最优，**不做任何伪随机抽样**；
约束冲突在输入校验阶段直接拒绝。

## 环境与依赖

- Python **3.14.7**（3.10+ 的类型语法即可运行，目标环境为 3.14.7）
- **仅使用 Python 标准库**，安装 Python 后无需安装任何第三方依赖
- 完全离线：不需要网络、账号、密钥、数据库、中间件、云 API 或 Docker

在仓库根目录（本文件所在目录）执行：

## 公共接口

```python
from rna_fold import fold

result = fold(sequence, constraints=None, *,
              unpaired_scores=None, stack_score=None)
```

### 参数

- `sequence` (`str`)：RNA 序列，仅允许字符 `A C G U`（大小写敏感，小写拒绝），
  长度 **1 ≤ n ≤ 120**（空串 `""` 也允许，返回空结构）。
- `constraints`（可选）：三种形式
  - `None`：自由折叠；
  - `str`：长度必须等于序列长度，支持
    - `.` 该位置自由；
    - `x` 该位置**强制未配**；
    - 成对括号 `()`、`[]`、`{}`、`<>`：括号配平，其两端位置**强制配对**；
  - `dict`：`{"pairs": [(i, j), ...], "unpaired": [k, ...]}`，所有下标 **0 基**。
    - `"pairs"`：强制配对 `(i, j)`，要求 `i < j` 且 `j - i >= 4`；
    - `"unpaired"`：强制未配位置；两个键都可省略。
- `unpaired_scores`（仅关键字，可选）：长度等于序列长度的**整数可迭代对象**
  （不接受字符串/字节）；位置 `p` 未配对时总分加 `unpaired_scores[p]`。
  默认全 0；允许负值（未配对要付出代价）。
- `stack_score`（仅关键字，可选）：**相邻嵌套奖励**整数。当且仅当 `(i, j)`
  与 `(i+1, j-1)` **同时存在**时加一次该分值（每个相邻堆栈恰好计一次）。
  默认 0；允许负值（可表达相邻嵌套惩罚）。新参数只改变打分，原配对分值与
  全部硬约束（最小环长、互补、不交叉、端点唯一、强制配对/未配）继续生效。

### 返回值（普通 `dict`，不暴露可变内部状态）

| 键 | 类型 | 含义 |
|---|---|---|
| `score` | `int` | 最大总分 = 配对分（GC/CG=3、AU/UA=2、GU/UG=1）+ 各未配位置分值之和 + 相邻嵌套奖励之和 |
| `structure` | `str` | 最优结构中**字典序最小**的 dot-bracket（`(`、`)`、`.`） |
| `count` | `int` | 最优结构数量，模 **1 000 000 007** |
| `pairs` | `tuple[(i, j), ...]` | **所有至少出现在某个最优结构中**的配对，按 `(i,j)` 升序 |

字典序按 ASCII 码比较，即 `'(' < ')' < '.'`。

另有打分助手（仅核算给定结构，不做优化）：

```python
from rna_fold import score_structure
score_structure(sequence, structure,
                unpaired_scores=None, stack_score=0) -> int
```

`structure` 必须是与序列等长的平衡 dot-bracket；配对不互补、间距不足、括号
不配平或含非法字符都会抛出带位置信息的 `ConstraintError`。

### 合法结构规则（题面契约）

- 只允许 `AU, UA, GC, CG, GU, UG` 六种配对；
- 每对内部至少 **3 个未配位点**：`j - i >= 4`（最小发夹环为 3 nt）；
- 禁止交叉（无假结），每个位置最多参与一个配对。

## 错误语义（异常层级）

所有错误消息都带可定位信息（0 基位置或 `pairs[k]` / `unpaired[k]` 条目名），
**不静默纠正、不猜测**。`fold` 是纯函数，失败不修改入参，不存在部分变更。

- `rna_fold.InvalidSequenceError(ValueError)`：序列类型错误、长度超 120、非法字符。
- `rna_fold.ConstraintError(ValueError)`：约束**结构性**非法：
  - 类型错误、下标越界、整数位置传入 `bool`/`NaN`/`Infinity`/非整数浮点；
  - 字符串约束长度不符、括号不配平、含非法字符；
  - 强制配对本身不合法（距离不足、碱基不互补）；
  - 两对强制配对共用端点、彼此交叉、或端点同时被强制未配；
  - `dict` 形式含未知键。
- `rna_fold.UnsatisfiableConstraintError(ConstraintError)`：
  约束良构但被**精确搜索证明无解**。当前实现下，单个强制配对的物理可行性
  （距离、互补性）与配对间冲突已在输入校验全部拒绝，因此正常输入不会到达此分支；
  保留该异常是为了让「证明无解」这一语义有稳定、可捕获的公开类型。
- `rna_fold.BudgetExceededError(RuntimeError)`：
  **搜索预算耗尽**（未能证明最优）。它与「证明无解」是刻意分开的两个类型，
  互不构成子类。由于 n ≤ 120 时精确 DP 总是完整枚举整个解空间，本实现**永不
  抛出**该异常；它作为固定错误语义的一部分保留。

数值输入契约：整数参数拒绝 `bool`（`True/False` 不当作 1/0）；`float` 的
`NaN`/`Infinity` 分别按名称拒绝，其他非整数浮点报 `TypeError`。

## 算法与设计取舍

- **带边界状态的区间 DP（离散打分，非能量模型）**：对半开区间 `[i, j)` 维护
  三张互不相交的表——`f`（全部结构）、`c`（边界恰为配对 `(i,j-1)` 的结构）、
  `nb`（边界不配对的结构），`f` 是 `c` 与 `nb` 的不交并。转移：
  - `i` 未配：`up[i] + f[i+1][j]`（归入 `f` 与 `nb`）；
  - `i` 与 `t` 配对：`w(i,t) + f[t+1][j] + 最优内部`，内部取
    `c[i+1][t] + stack_score`（内部边界配对，加一次相邻嵌套奖励）与
    `nb[i+1][t]`（内部边界不配对）两者的较优者；`t = j-1` 归入 `c`，
    其余归入 `nb`。

  必须区分边界是否**实际配对**：相邻嵌套奖励只取决于 `(i,j)` 与 `(i+1,j-1)`
  是否同时存在，无法在最终 dot-bracket 上事后补奖而不重复计数。`c`/`nb`
  互斥的划分保证**每个结构恰好被计数一次**——即使同一匹配存在多种区间分解
  路径，路径重复也不会抬高 `count`。
  时间 O(n³)、空间 O(n²)；n=120 实测约 0.2 秒（含全部新分值）。
- **强制约束的处理**：除逐位置的配对/未配限制外，引入「闭区间」表
  `closed[i][j]`——区间内任何有强制配偶的位置，其配偶也必须在区间内。
  DP 只在闭子区间上转移，于是任何与强制配对交叉的选择都会使某个子区间不闭，
  自动不可达，不需要特判交叉。
- **计数**：三张表各自与最优分同步累加，加法处理互斥候选、乘法处理
  内外独立组合，随时对 1 000 000 007 取模。
- **字典序最小结构**：对 `f`/`c`/`nb` 三表分别从短到长收集全部最优分解片段，
  取 ASCII 最小者（`'(' < ')' < '.'`）。
- **可出现在最优中的配对**：从根区间沿「保持最优分值」的决策对三张表统一下
  降遍历做可达性传播；可达区间上的任何最优配对都至少属于一个全局最优结构。
  可达性只由分值表（可行性）决定，**不使用取模后的计数**，因此即使某子结构
  集合数量恰为模数倍数（计数显示 0），配对集合仍然精确。旧测试
  `test_pair_set_independent_of_count_modulus` 用小模数白盒验证了这一点。

### 与独立参考的关系

`tests/brute_reference.py` 是**从零编写、不导入被测模块**的独立参考：
对 n ≤ 14 递归枚举全部非交叉匹配，独立计算配对分、每位置未配对分，并在发现
`(i,t)` 内部恰好含 `(i+1,t-1)` 时加一次 `stack_score`；再以「事后过滤」方式
保留含全部强制配对的结构（与生产代码的三态 DP 是两套独立机制），独立给出
最大分、字典序最小串、**精确**最优数量与最优配对集合。测试在数百个确定性
随机序列（固定种子）上对正/负 stack、正/负未配对分及其组合逐字段对拍；
`tests/test_scoring.py` 还专门覆盖负 stack 导致堆栈解散、未配奖励胜过配对、
强制堆栈仍须支付负奖励、以及同一结构多种分解路径下计数只算一次等场景。
往返一致性（返回串自身合法、`score_structure` 能复算所报分值）仅作为补充断言。

## 数值/误差口径

- 分值与计数均为**整数精确计算**：分值是小整数精确加法；计数只做模
  1 000 000 007 的精确整数运算。**全程无浮点参与**，因此没有浮点误差或容差，
  也不存在用宽容差掩盖边界错误的情况。
- 唯一的浮点出现在 `demo.py` 的耗时显示（`time.perf_counter()`，仅展示用，
  不参与任何结果判定）。

## 已知限制（按本题契约实现，不宣称行业标准兼容）

- 这是题面定义的**离散整数打分模型**，**不是真实 RNA 热力学/自由能预测**：
  无最近邻能量参数、无温度、无 kcal/mol、无凸包/多分支环能量项，新增的
  `stack_score` 只是用户给定的一个整数相邻嵌套奖励，不使用也不内置任何真实
  热力学参数，不与 ViennaRNA 等行业标准兼容，不应据此解读为真实 RNA 能量。
- 禁止假结（非交叉）；不预测三链、修饰碱基、非 `ACGU` 字母（如 N、I）。
- 只输出单一字典序最小最优结构；其余并列最优结构以 `count` 与 `pairs` 概括，
  不逐个枚举（n=120 时枚举全部结构不现实）。
- `BudgetExceededError` 在当前确定性 DP 下不会被抛出；它是为语义完整性保留的
  公开类型。
