# rna_fold — 带强制配对的 RNA 二级结构预测

离线、纯标准库的可复用模块：在固定打分模型下求 RNA 序列的最大分值二级结构，
支持强制配对 / 强制未配硬约束，并返回字典序最小 dot-bracket、最优结构数
（模 1_000_000_007）以及所有可出现在某个最优结构中的配对。

## 环境

- Python 3.14.7（开发验证版本；仅使用标准库，语法兼容 3.10+）
- 无需安装任何第三方依赖；核心、测试、演示全部离线运行

## 接口

```python
from rna_fold import fold, Constraints, FoldResult, FoldError, SequenceError, ConstraintError

result = fold(sequence, constraints=None)
```

- `sequence`：`str`，仅含大写 `A`/`C`/`G`/`U`，长度 `0..120`（`MAX_LENGTH = 120`）。
- `constraints`：`None`、`Constraints` 实例，或 dict（可选键 `forced_pairs`、`unpaired`，
  值为 `None` 时视为空）。位置均为 0 基索引。
  - `forced_pairs`：`(i, j)` 可迭代，`i < j`，该配对必须出现在每个最优结构中；
  - `unpaired`：必须保持未配的位置。

`FoldResult`（frozen dataclass）：

| 字段 | 含义 |
|---|---|
| `score` | 最大总分值（精确整数） |
| `structure` | 所有最优结构中字典序最小的 dot-bracket（ASCII 序：`'(' < ')' < '.'`） |
| `count` | 最优结构数量，模 `MOD = 1_000_000_007` |
| `pairs` | 出现在至少一个最优结构中的全部 `(i, j)` 配对（`frozenset`，0 基，`i < j`） |

### 结构模型（按本题契约，非完整热力学模型）

- 允许配对：AU/UA=2 分，GC/CG=3 分，GU/UG=1 分；
- 每个配对 `(i, j)` 要求 `j - i >= 4`（配对两端之间至少 3 个未配位点，`MIN_LOOP = 3`）；
- 配对不交叉（不允许假结），每个位置最多参与一个配对；
- 强制未配 / 强制配对为硬约束。

### 错误语义

所有错误均继承自 `FoldError`：

- `SequenceError`（也是 `ValueError`）：序列类型错误、长度超过 120、含非法字符
  （报错信息含出错位置）；
- `ConstraintError`（也是 `ValueError`）：约束格式非法或自相矛盾，包括——
  位置非整数（`bool`、`float` 含 NaN/Infinity、字符串等均拒绝）、位置越界、
  `i >= j`、配对跨度不足 4、强制配对的碱基不可配、两个强制配对共用位置或交叉、
  强制配对与强制未配冲突、未知约束键。

非法输入一律抛出可定位的异常，不做静默纠正。约束冲突属于"证明无解"，
在计算前确定性地拒绝；本模块算法为精确多项式时间动态规划（O(n³) 时间、
O(n²) 空间），不存在搜索预算，因此没有"预算耗尽"这一失败类别。

## 精度口径

输出不含任何浮点数：`score` 为精确整数，`count` 为模 1_000_000_007 的精确剩余，
`structure`/`pairs` 为离散对象。因此没有浮点误差或容差问题。

## 设计取舍

- **精确 DP，不用采样**：Nussinov 风格 inside/outside 区间动态规划
  （O(n³) 时间、O(n²) 空间）。inside 表按"位置 i 未配 / 与 k 配对 / i 是强制配对
  左端点（确定性转移）"分解，同时求出分值、最优计数（转移时取模）与字典序最小
  结构；outside 表给出每个区间补集上的最大分值。
- **强制配对 → 区间合法性**：强制配对互不交叉，一个区间合法当且仅当它不切断任何
  强制配对（用端点前缀和 O(1) 判定）。强制配对左端点在 inside 递归中确定性展开，
  自由配对不允许触碰强制端点与强制未配位置。
- **可出现在最优中的配对**：自由配对 `(i, k)` 当且仅当
  `w(i,k) + best[i+1][k] + out[i][k+1] == best[0][n]` 时出现在某个最优结构中
  （给定该配对后，其内部与补集相互独立）；强制配对属于每个结构，直接并入。
- **测试的独立参考**：`tests/reference_impl.py` 用朴素递归穷举所有非交叉匹配
  直接打分，不调用被测核心；对长度 ≤ 14 的确定性序列逐字段比对。

## 已知限制

- 不允许假结（交叉配对）——这是模型契约，不是实现疏漏；
- 固定打分（GC=3/AU=2/GU=1），不考虑碱基堆叠、环熵等热力学项，
  不宣称与任何行业标准能量模型兼容；
- 序列长度上限 120，超出即拒绝；
- `count` 只给出模 1_000_000_007 的剩余，不给出精确大整数；
- 只接受大写 `ACGU`，不做大小写或简并碱基的静默转换。
