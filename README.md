# RNA 二级结构预测（带强制配对）

离线、纯标准库实现的「带强制配对的 RNA 非交叉（无假结）二级结构预测」可复用模块。
核心算法为**精确区间动态规划**，穷举所有合法结构求最优，**不做任何伪随机抽样**；
约束冲突在输入校验阶段直接拒绝。

## 环境与依赖

- Python **3.14.7**（3.10+ 的类型语法即可运行，目标环境为 3.14.7）
- **仅使用 Python 标准库**，安装 Python 后无需安装任何第三方依赖
- 完全离线：不需要网络、账号、密钥、数据库、中间件、云 API 或 Docker

在仓库根目录（本文件所在目录）执行：


## 公共接口

```python
from rna_fold import fold

result = fold(sequence, constraints=None)
from rna_fold import claim_optimal_structures

batch = claim_optimal_structures(sequence, constraints=None, limit=10, cursor=None)
```

### 参数

- `sequence` (`str`)：RNA 序列，仅允许字符 `A C G U`（大小写敏感，小写拒绝），
  长度 **1 ≤ n ≤ 120**（空串 `""` 也允许，返回空结构）。
- `constraints`（可选）：三种形式
  - `None`：自由折叠；
  - `str`：长度必须等于序列长度，支持
    - `.` 该位置自由；
    - `x` 该位置**强制未配**；
    - 成对括号 `()`、`[]`、`{}`、`<>`：括号配平，其两端位置**强制配对**；
  - `dict`：`{"pairs": [(i, j), ...], "unpaired": [k, ...]}`，所有下标 **0 基**。
    - `"pairs"`：强制配对 `(i, j)`，要求 `i < j` 且 `j - i >= 4`；
    - `"unpaired"`：强制未配位置；两个键都可省略。

### 返回值（普通 `dict`，不暴露可变内部状态）

| 键 | 类型 | 含义 |
|---|---|---|
| `score` | `int` | 最大总分：GC/CG=3，AU/UA=2，GU/UG=1 |
| `structure` | `str` | 最优结构中**字典序最小**的 dot-bracket（`(`、`)`、`.`） |
| `count` | `int` | 最优结构数量，模 **1 000 000 007** |
| `pairs` | `tuple[(i, j), ...]` | **所有至少出现在某个最优结构中**的配对，按 `(i,j)` 升序 |

字典序按 ASCII 码比较，即 `'(' < ')' < '.'`。

### 并列最优结构的分批领取：`claim_optimal_structures`

当多个结构同分并列、而 `fold()` 只返回字典序最小者时，可用本接口按批次继续
领取其余并列最优结构。

```python
first  = claim_optimal_structures(sequence, constraints, limit=10)
second = claim_optimal_structures(sequence, constraints, limit=10,
                                 cursor=first["next_cursor"])
```

参数 `sequence`、`constraints` 与 `fold()` 完全一致；`limit` 为每批数量，
要求 `1 <= limit <= 100`（`bool` 按整数契约拒绝）。

| 返回键 | 类型 | 含义 |
|---|---|---|
| `structures` | `tuple[str, ...]` | 本批 dot-bracket，按字典序升序 |
| `score` | `int` | 共同的最优分值 |
| `count` | `int` | 最优结构总数（模 1 000 000 007），与已领取多少无关 |
| `next_cursor` | `str \| None` | 不透明续取令牌；全部领完为 `None` |
| `done` | `bool` | 恰在 `next_cursor is None` 时为 `True` |

语义保证：

- **每个返回结构都合法且最优**：满足全部强制配对/强制未配、最短发夹环、
  互补、非交叉、单位置单配等全部硬约束，并达到最优分值。
- **稳定顺序、绝不重复**：领取顺序为 dot-bracket 的严格字典序
  （ASCII：`'(' < ')' < '.'`）；跨批次按游标顺序推进，同一结构不会返回两次。
- **惰性展开**：未领取的结构不会提前在内存中展开。每次调用只做
  “给定上界后的严格后继”有界搜索（本批 `limit` 个 + 判断是否结束的一次探测），
  不在服务端/模块侧保存任何枚举状态；除游标字符串外，调用之间无隐藏状态。
- **游标与输入绑定**：游标内带（序列 + 规范化后的约束）的 SHA-256 指纹与
  HMAC 式完整性标记。换了序列（哪怕只差一个字符）或换了约束都不能沿用，
  直接抛 `CursorError`；等价的约束写法（如自由折叠与全 `.` 串）规范化后
  相同，可以沿用。游标是一次性的“续取位置”，可以安全地跨进程/序列化传递，
  但不应被当作可人工解析的数据结构（格式 `rf1_...`，不保证跨版本兼容）。

### 合法结构规则（题面契约）

- 只允许 `AU, UA, GC, CG, GU, UG` 六种配对；
- 每对内部至少 **3 个未配位点**：`j - i >= 4`（最小发夹环为 3 nt）；
- 禁止交叉（无假结），每个位置最多参与一个配对。

## 错误语义（异常层级）

所有错误消息都带可定位信息（0 基位置或 `pairs[k]` / `unpaired[k]` 条目名），
**不静默纠正、不猜测**。`fold` 是纯函数，失败不修改入参，不存在部分变更。

- `rna_fold.InvalidSequenceError(ValueError)`：序列类型错误、长度超 120、非法字符。
- `rna_fold.ConstraintError(ValueError)`：约束**结构性**非法：
  - 类型错误、下标越界、整数位置传入 `bool`/`NaN`/`Infinity`/非整数浮点；
  - 字符串约束长度不符、括号不配平、含非法字符；
  - 强制配对本身不合法（距离不足、碱基不互补）；
  - 两对强制配对共用端点、彼此交叉、或端点同时被强制未配；
  - `dict` 形式含未知键。
- `rna_fold.UnsatisfiableConstraintError(ConstraintError)`：
  约束良构但被**精确搜索证明无解**。当前实现下，单个强制配对的物理可行性
  （距离、互补性）与配对间冲突已在输入校验全部拒绝，因此正常输入不会到达此分支；
  保留该异常是为了让「证明无解」这一语义有稳定、可捕获的公开类型。
- `rna_fold.CursorError(ValueError)`：续取游标损坏、被篡改，或与本次传入的
  （序列、约束）不一致（包括换了序列仍沿用旧游标）。
- `rna_fold.BudgetExceededError(RuntimeError)`：
  **搜索预算耗尽**（未能证明最优）。它与「证明无解」是刻意分开的两个类型，
  互不构成子类。由于 n ≤ 120 时精确 DP 总是完整枚举整个解空间，本实现**永不
  抛出**该异常；它作为固定错误语义的一部分保留。

数值输入契约：整数参数拒绝 `bool`（`True/False` 不当作 1/0）；`float` 的
`NaN`/`Infinity` 分别按名称拒绝，其他非整数浮点报 `TypeError`。

## 算法与设计取舍

- **区间 DP（Zuker 式简化版，无能量模型）**：对半开区间 `[i, j)`，
  `best[i][j] = max(best[i+1][j],  max_t {w(i,t) + best[i+1][t] + best[t+1][j]})`，
  `t` 从 `i+4` 起，且 `(i,t)` 必须互补、不违反强制约束。
  时间 O(n³)、空间 O(n²)；n=120 实测约 0.15 秒。
- **强制约束的处理**：除逐位置的配对/未配限制外，引入「闭区间」表
  `closed[i][j]`——区间内任何有强制配偶的位置，其配偶也必须在区间内。
  DP 只在闭子区间上转移，于是任何与强制配对交叉的选择都会使某个子区间不闭，
  自动不可达，不需要特判交叉。
- **计数**：与最优表同步用加法/组合乘法累加，随时对 1 000 000 007 取模。
- **字典序最小结构**：第二张区间表从短到长重建；同一最优分值下，
  `i` 未配的候选为 `"."+...`，`i` 配对的候选为 `"("+...+")"+...`，
  取 ASCII 最小者。配对候选按 `t` 升序取最小。
- **可出现在最优中的配对**：从根区间 `[0,n)` 沿「保持最优分值」的决策做
  可达性传播；可达区间上的任何最优配对都至少属于一个全局最优结构。
  可达性只由分值表（可行性）决定，**不使用取模后的计数**，因此即使某子结构
  集合数量恰为模数倍数（计数显示 0），配对集合仍然精确。测试
  `test_pair_set_independent_of_count_modulus` 用小模数白盒验证了这一点。
- **并列最优的惰性枚举（批次领取）**：DP 为每个区间额外记录其最优决策
  “模板”（固定括号字符 + 指向子区间最优集的节点），但**不实例化**具体结构。
  枚举器只在领取时回答两个查询：串 `s` 是否属于某区间的最优集
  （membership），以及严格大于 `s` 的最小最优串（successor）。后继搜索在模板的
  “分歧节点”上组合：分歧点之前必须与上界逐段相等，分歧点要么是一个变大的
  固定字符、要么是某个子区间自己的后继，分歧点之后各子区间取各自字典序最小。
  因此每批只展开 `limit` 个后继与一次结束探测，未领取的结构始终不进入内存；
  内存主要仍为 DP 的 O(n²) 表，n=120 实测约 23 MB RSS。

### 与独立参考的关系

`tests/brute_reference.py` 是**从零编写、不导入被测模块**的独立参考：
对 n ≤ 14 递归枚举全部非交叉匹配，再以「事后过滤」方式保留含全部强制配对的
结构（与生产代码的闭区间 DP 是两套独立机制），独立给出最大分、字典序最小串、
精确最优数量与最优配对集合。测试在数百个确定性随机序列（固定种子）上逐字段对拍。
往返一致性（返回串自身合法、能达到所报分值）仅作为补充断言。

## 数值/误差口径

- 分值与计数均为**整数精确计算**：分值是小整数精确加法；计数只做模
  1 000 000 007 的精确整数运算。**全程无浮点参与**，因此没有浮点误差或容差，
  也不存在用宽容差掩盖边界错误的情况。
- 唯一的浮点出现在 `demo.py` 的耗时显示（`time.perf_counter()`，仅展示用，
  不参与任何结果判定）。

## 已知限制（按本题契约实现，不宣称行业标准兼容）

- 这是题面定义的**简化打分模型**，不是完整 RNA 折叠能量模型（无最近邻能量、
  无温度、无自由能 kcal/mol、无堆栈/凸包/多分支环能量项），不与 ViennaRNA 等
  行业标准兼容。
- 禁止假结（非交叉）；不预测三链、修饰碱基、非 `ACGU` 字母（如 N、I）。
- `fold()` 只输出单一字典序最小最优结构；其余并列最优结构可通过
  `claim_optimal_structures()` 按批次稳定领取（见上文）。未领取的结构不会被提前
  展开；但**同一输入的并列最优结构总数可能是指数级**，实际逐批全部领完仍受该
  总数限制——接口保证的是“不提前展开”，而不是“指数结构变多项式输出”。
- `BudgetExceededError` 在当前确定性 DP 下不会被抛出；它是为语义完整性保留的
  公开类型。
